# Requirements: MonkeyLines

**Defined:** 2026-02-07
**Core Value:** Immediate clarity, nostalgic recognition, intuitive interaction

## v1 Requirements

Requirements for Monkey Island-styled UI revamp. Each maps to roadmap phases.

### Visual Foundation

- [x] **VFND-01**: Monkey Island color palette defined as CSS custom properties (deep purples, teals, ambers, cream) — ✅ Shipped in Phase 1
- [x] **VFND-02**: Press Start 2P pixel font loaded (self-hosted WOFF2, antialiasing disabled) — ✅ Shipped in Phase 1
- [x] **VFND-03**: Consistent `image-rendering: pixelated` applied to all pixel art elements — ✅ Shipped in Phase 1
- [x] **VFND-04**: Base theme colors applied to body and container elements — ✅ Shipped in Phase 1

### Button Controls

- [x] **CTRL-01**: Button touch targets meet 44x44px minimum for mobile compatibility — ✅ Shipped in Phase 2
- [x] **CTRL-02**: Verb bar panel styling (dark background strip, SCUMM two-zone layout below scene) — ✅ Shipped in Phase 2
- [x] **CTRL-03**: Pixel art button icons created (16x16 or 32x32 sprites in MI palette) — ✅ Adjusted: Hybrid approach with text labels for Fight/Auto, speaker icon for mute
- [x] **CTRL-04**: Pixel art icons replace emoji buttons for all three controls — ✅ Adjusted: Hybrid approach, speaker icon for mute, text labels for Fight/Auto (more authentic to SCUMM)

- [x] **SCNE-01**: Scene frame/border added around monkey viewport (pixel art or CSS in MI palette) — ✅ Shipped in Phase 3

- [x] **SCNE-03**: 9-slice border-image panels for authentic SCUMM-style scalable borders — ✅ Shipped in Phase 3, applied to scene frame
- [x] **SCNE-04**: Speech bubble restyled with pixel aesthetic (preserves fitText() functionality) — ✅ Shipped in Phase 3, used existing background bubble with per-speaker colors

### Polish

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Additional gameplay features | Focus is UI polish, not new functionality |
| Backend/server changes | Go server and exchange logic work perfectly as-is |
| New content themes | Existing 8 themes provide sufficient variety |
| User accounts or persistence | Stateless design is intentional and appropriate |
| Multiple monkey characters | Three-headed monkey is the core concept |
| Framework migration | Vanilla HTML/CSS/JS constraint is a feature, not limitation |
