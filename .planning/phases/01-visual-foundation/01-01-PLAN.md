<task type="auto">
  <name>Task 1: Add pixel font and define MI color palette</name>
  <files>index.html, images/fonts/PressStart2P-Regular.woff2</files>
  <action>
1. Download Press Start 2P WOFF2 from Google Fonts CDN (https://fonts.gstatic.com/s/pressstart2p/v15/e3t4euO8T-267oIAQAu6jDQyK3nVivM.woff2) and save to `images/fonts/PressStart2P-Regular.woff2`. Create the `images/fonts/` directory first.

2. In index.html `<style>` block, add at the top (before the `*` reset):

```css
@font-face {
  font-family: 'Press Start 2P';
  src: url('/images/fonts/PressStart2P-Regular.woff2') format('woff2');
  font-display: swap;
}

:root {
  --mi-bg-dark: #1a0a2e;
  --mi-bg-mid: #2d1b4e;
  --mi-teal: #2d8b6e;
  --mi-teal-light: #3aaf8a;
  --mi-amber: #c8a43c;
  --mi-amber-light: #e8c84c;
  --mi-cream: #e8d4a0;
  --mi-text: #e8d4a0;
  --mi-text-dark: #1a0a2e;
  --mi-border: #4a2d6e;
}
```

3. Apply the pixel font globally on `body`:
```css
font-family: 'Press Start 2P', monospace;
-webkit-font-smoothing: none;
-moz-osx-font-smoothing: unset;
text-rendering: optimizeSpeed;
```

Note: Keep `monospace` as fallback so layout doesn't break while font loads. The `font-display: swap` ensures text is visible immediately with fallback, then swaps in the pixel font.
  </action>
  <verify>
Run `go run main.go` and open http://localhost:8080 in browser. Verify:
- Font loads (check Network tab for PressStart2P-Regular.woff2, 200 status)
- Text appears pixelated with no antialiasing smoothing
- CSS custom properties visible in DevTools on :root
  </verify>
  <done>Press Start 2P font loads from self-hosted WOFF2. CSS custom properties for MI palette defined on :root. Body uses pixel font with antialiasing disabled.</done>
</task>
