   - `repeat.png`: Circular arrows (auto-play)
   - `speaker-on.png`: Speaker with sound waves
   - `speaker-off.png`: Speaker with X mark

   Use Python with PIL/Pillow to draw these programmatically at exactly 32x32 pixels. Keep designs simple filled silhouettes — SCUMM style was minimal. Save as PNG with transparency.

3. In `index.html`, replace the `.btn-row` div with a `.verb-bar` div:
   ```html
   <div class="verb-bar">
       <button class="verb-btn" id="reload-btn" aria-label="New exchange">
           <img src="/images/icons/sword.png" alt="" width="32" height="32">
       </button>
       <button class="verb-btn" id="auto-btn" aria-label="Auto-play">
           <img src="/images/icons/repeat.png" alt="" width="32" height="32">
       </button>
       <button class="verb-btn" id="mute-btn" aria-label="Toggle sound">
           <img src="/images/icons/speaker-off.png" alt="" width="32" height="32">
       </button>
   </div>
   ```

4. Replace `.btn-row` and `.dialogue-btn` CSS with verb bar styles:
   ```css
   .verb-bar {
       background: var(--mi-bg-dark);
       border-top: 3px solid var(--mi-border);
       padding: 12px;
       display: flex;
       justify-content: center;
       gap: 16px;
   }
   .verb-btn {
       min-width: 44px;
       min-height: 44px;
       padding: 6px 12px;
       background: var(--mi-bg-mid);
       border: 2px solid var(--mi-border);
       border-radius: 0;
       cursor: pointer;
       display: flex;
       align-items: center;
       justify-content: center;
   }
   .verb-btn img {
       image-rendering: pixelated;
       display: block;
   }
   .verb-btn:active:not(:disabled) {
       transform: translateY(2px);
   }
   .verb-btn:disabled {
       opacity: 0.3;
       cursor: default;
   }
   .verb-btn.active {
       border-color: var(--mi-teal);
   }
   ```
   Remove the old `.btn-row` margin/gap styles. Remove `.dialogue-btn` font-size, border-radius: 16px, box-shadow styles. The verb bar should be boxy/rectangular (border-radius: 0) for SCUMM authenticity.

5. Update the mobile `@media (max-aspect-ratio: 1/1)` block: replace `.btn-row` reference with `.verb-bar` if needed. The verb bar should inherit full width on mobile.

6. Update the mute toggle JS: change `muteBtn.textContent = muted ? '...' : '...'` to swap the img src:
   ```javascript
   var muteIcon = muteBtn.querySelector('img');
   muteIcon.src = muted ? '/images/icons/speaker-off.png' : '/images/icons/speaker-on.png';
   ```

Important: The initial mute state is `true` (muted), so the initial icon should be `speaker-off.png`. Do NOT use rounded corners on buttons — keep border-radius: 0 for SCUMM authenticity. Do NOT add box-shadow to verb buttons — keep them flat.
