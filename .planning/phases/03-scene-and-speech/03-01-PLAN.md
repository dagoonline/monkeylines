  <name>Task 1: Scene frame with pixel-art 9-slice border</name>
  <files>index.html</files>
  <action>
Add a visible pixel-art border/frame around `.monkey-scene` to create a "screen within screen" effect.

Two approaches (choose based on what renders best):

**Option A - Inline data URI (preferred, no extra files):**
Create a small pixel-art PNG (24x24 or 48x48) as a base64 data URI. The border should use MI palette colors (--mi-border purple, --mi-teal accents). Use it as border-image-source.

**Option B - Pure CSS fallback:**
If data URI approach has rendering issues, use a multi-layer box-shadow or nested border approach with solid MI palette colors to simulate a pixel frame.

CSS for `.monkey-scene`:
```css
border: 8px solid transparent;
border-image-source: url('data:image/png;base64,...');
border-image-slice: 8;
border-image-width: 8px;
border-image-repeat: round;
image-rendering: pixelated;
```

Key constraints from research:
- Use `border-image-repeat: round` not `stretch` (avoids blurring)
- Use integer pixel values only (no sub-pixel artifacts)
- `border-radius` is ignored with border-image, don't combine them
- Keep `border-image-outset: 0` to avoid overflow/scrollbar issues
- `image-rendering: pixelated` on the element for crisp pixel art

The frame should be visually distinct -- a clear ornamental border that says "this is the game screen." Think SCUMM viewport border: dark with colored accent pixels at corners/edges.
  </action>

**Part A - Speaker colors:**

Add CSS custom properties for 3 speaker colors (readable against dark background):
```css
:root {
    --mi-speaker-l: #e8c84c;   /* left head - amber/yellow */
    --mi-speaker-c: #3aaf8a;   /* center head - teal/green */
    --mi-speaker-r: #c87040;   /* right head - orange/rust */
}
```

Add CSS rules using data-speaker attribute:
```css
.speech-text[data-speaker="l"] { color: var(--mi-speaker-l); }
.speech-text[data-speaker="c"] { color: var(--mi-speaker-c); }
.speech-text[data-speaker="r"] { color: var(--mi-speaker-r); }
```

In the `typeText()` JS function, set the data-speaker attribute on `el` before typing begins:
```javascript
el.setAttribute('data-speaker', monkey);
```

**Part B - Speech bubble pixel border:**

Add a 9-slice pixel-art border to `.speech-text` (similar approach as scene frame but smaller/different style). Also add a solid or semi-opaque dark background so colored text is readable against any base image content:

```css
.speech-text {
    background: var(--mi-bg-dark);
    background-clip: padding-box;
    border: 4px solid transparent;
    border-image-source: url('data:image/png;base64,...');
    border-image-slice: 4;
    border-image-width: 4px;
    border-image-repeat: round;
}
```

Use `border-image-slice: N fill` if you want the center of the border image to fill (acts as background).

**Critical:** After adding border/padding changes, verify `fitText()` still works correctly. The function compares `el.scrollHeight > el.clientHeight` -- adding border-width changes the box model. Test with long text. Adjust height percentage or padding if text overflows or becomes too small.

Remove the existing `color: var(--mi-text-dark)` from `.speech-text` base rule since speaker colors now handle text color via data-speaker.
