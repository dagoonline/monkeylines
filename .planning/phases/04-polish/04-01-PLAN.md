  <files>index.html</files>
  <action>
Add CSS scanline effect to `.monkey-scene` using a `::before` pseudo-element with the following specific implementation:

**Base scanline effect:**
- Create `.monkey-scene::before` selector in the `<style>` block
- Properties:
  - `content: ""`
  - `display: block`
  - `position: absolute` with `top: 0; left: 0; right: 0; bottom: 0`
  - `background: linear-gradient(to bottom, transparent 0, transparent 50%, rgba(0, 0, 0, 0.2) 50%, rgba(0, 0, 0, 0.2) 100%)`
  - `background-size: 100% 4px` (creates 4px repeat pattern: 2px transparent, 2px scanline)
  - `z-index: 10` (above monkey images, below speech text which should be z-index 20+)
  - `pointer-events: none` (critical - prevents blocking clicks/taps on underlying scene)

**Accessibility support:**
Add `@media (prefers-reduced-motion: reduce)` query that reduces scanline opacity to 0.5 or removes effect entirely with `display: none`. Use opacity reduction approach to maintain visual consistency while respecting user preferences.

**Optional mobile optimization (only if needed during testing):**
If performance testing in Task 2 reveals jank on mobile, add `transform: translateZ(0)` to trigger GPU acceleration. Do NOT add this preemptively - test first.

**What to avoid:**
- Do NOT use `will-change` property (wastes memory for static overlays)
- Do NOT animate the gradient (causes performance issues)
- Do NOT use opacity above 0.25 (research shows this reduces text readability with pixel fonts)
- Do NOT use patterns smaller than 2px (causes rendering issues on some devices)
- Do NOT forget `pointer-events: none` (would block all interactions with scene)

**Z-index layering (verify in existing CSS):**
Ensure stacking order is: base monkey image (natural) → monkey overlays (natural) → scanlines (z-index: 10) → speech text (should have z-index: 20 or higher). If speech text doesn't have z-index set, add it.

**Placement in CSS:**
Add the `.monkey-scene::before` rule immediately after the existing `.monkey-scene` rule (around line 68-80) to keep related styles together. Add the `@media (prefers-reduced-motion)` query at the end of the `<style>` block with other media queries.
